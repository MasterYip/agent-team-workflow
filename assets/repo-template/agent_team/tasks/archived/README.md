# Archived Tasks

Archived task records live at `<classname>/YYYYMMDD_TASK-ID/` beneath this
directory. The class is the broad leading task-ID prefix: every `ENV-*` task is
grouped under `ENV/`, every `RL-*` task under `RL/`, and `DOC-*` under `DOC/`.
Do not create one archive class per narrow task family.

Only tasks whose portfolio status is `archived` belong here. Update all canonical
links as part of the same lifecycle change and keep no duplicate at the old path.
